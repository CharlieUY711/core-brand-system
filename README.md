# CORE Brand & System

Official brand, visual system and corporate architecture portal for CORE.

## Scope

This repository contains the public-facing CORE Brand & System portal and its supporting identity resources.

### Brand
- Brand Guidelines
- Logo & Assets
- Color System
- Typography
- CORE Orbit

### System
- CORE Logistics — technology layer for OnDemand logistics operations
- CORE Rep
- CORE Market — technology layer for COMITA commerce
- CORE Intelligence
- CORE Finance

### Corporate Architecture
- ODDY — corporate ecosystem
- OnDemand — logistics operations, including free-zone and regional operations
- COMITA — commerce
- CORE — technology platform / system

### Resources
- SVG / PNG assets
- Favicon and app icons
- UI tokens

## Identity status

- CORE symbol: D3-C / N0-R0 — frozen
- ODDY logo: immutable; official asset only
- Primary typeface: IBM Plex
- CORE Ink: `#152238`
- CORE Signal: `#0E8A82`

## Architecture principle

> CORE provides the system. OnDemand operates logistics. COMITA develops commerce. ODDY articulates the corporate ecosystem.

## Repository status

The repository is being initialized from the approved CORE Brand & System v1.0 artifact. The artifact is the current visual and conceptual reference while the portal is migrated into a production web structure.
