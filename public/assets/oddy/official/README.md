# ODDY official asset

The official ODDY files are installed here. They come from the ODDY brand
package in `COREGROUP/assets/oddy/` and are reproduced byte-for-byte — never
redrawn, traced, recolored or approximated from the CORE symbol's geometry.

| File | Use |
|---|---|
| `logo-1024.png` | Logotype — screen |
| `logo-2048.png` | Logotype — print |
| `isotipo-512.png` | Ring symbol — screen, compact contexts |
| `isotipo-1024.png` | Ring symbol — larger reproduction |
| `favicon-192.png` | Browser / app icon |

## Rules

**The logotype only goes on light backgrounds.** It combines navy and blue; on
a dark ground the first "D" disappears and the mark reads "O DY". Where the
background is dark, use the isotipo, which works on any ground.

**Navy ODDY is `#0B2A61`.** Any other value is not ODDY's color.

**No vector master exists.** For large-format print use the 2048 px file. A
vector master is an open item on ODDY's side.

The mark is immutable: not modified, redesigned, reinterpreted or fused with
CORE anywhere in this system.

## Status of the placeholder convention

Before these files existed, any UI referencing ODDY used the
`ODDY OFFICIAL ASSET — INSERT OFFICIAL FILE` placeholder convention in
`components/architecture/EntityPage.tsx` and in
`app/(guidelines)/brand/guidelines/page.tsx` § 11 and § 17. Those placeholders
can now be replaced with the real asset.
