# ODDY OFFICIAL ASSET — INSERT OFFICIAL FILE

This directory intentionally has no logo file.

The ODDY brand asset is immutable and external to this repository. It must
never be redrawn, reinterpreted or approximated from the CORE symbol's
geometry.

To complete this directory, add the official ODDY logo file(s) exactly as
provided by the ODDY brand owner (e.g. `oddy-logo.svg`, `oddy-logo.png`).
Do not generate, trace or hand-recreate the mark.

Until an official file is added, any UI that needs to reference ODDY visually
must use the `ODDY OFFICIAL ASSET — INSERT OFFICIAL FILE` placeholder
convention used in `components/architecture/EntityPage.tsx` and throughout
`app/(guidelines)/brand/guidelines/page.tsx` § 11 and § 17.
