# Wordmark y lockup CORE Group — pendientes

Este directorio está vacío a propósito.

El wordmark CORE y el lockup CORE Group se componen en **IBM Plex Sans 700**
(§ 08–09). La única IBM Plex Sans presente en este repositorio es la fuente
**variable** del cache de `next/font`: se pueden extraer contornos de su
instancia por defecto —peso 400— pero pedirle la instancia 700 falla.

Generarlos en 400 sería publicar el logotipo con el peso equivocado, así que
no se generan. Falta una **IBM Plex Sans Bold estática**; con eso, se agregan
al script y aparecen acá.

Mientras tanto, la fuente de verdad de los lockups sigue siendo
`components/brand/*` y Brand Guidelines § 08–09.
